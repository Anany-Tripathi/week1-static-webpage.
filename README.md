# Week 1 — Transforming Wireframes into Static Web Pages

## Overview
Northstar is a fictional digital studio landing page created as a static webpage project. It uses semantic HTML5 and a separate CSS3 stylesheet, with responsive layouts and a self-contained CSS illustration.

## Files
- `index.html` — page structure and content
- `css/styles.css` — visual styling, responsive breakpoints, and reduced-motion support
- `REPORT.md` — project report in Markdown
- `docs/Week1_Static_Webpage_Report.docx` — downloadable Word report

## Run the page
Extract the ZIP and open `index.html` in a modern web browser. No installation, build command, server, or external library is required.

## Design and accessibility
The page includes semantic landmarks, a skip link, labeled navigation, visible keyboard focus, responsive layout changes, and reduced-motion handling. The hero illustration is constructed with CSS shapes.

## Validation checklist
- Test every navigation link.
- Check mobile, tablet, and desktop widths.
- Navigate using only the keyboard.
- Check focus visibility, text contrast, and horizontal overflow.
- Run Lighthouse or an accessibility checker and record the actual results.
